# Part H - Reflection
Before I used AI, I created a simple Python prototype using basic lists, and dictionaries to store patients' names, practitioners' names, and appointment times. I then asked Copilot to act as a tutor, and it helped me understand the importance of defensive error handling, such as verifying patient and practitioner names and checking for conflicting appointment times. However, the AI also suggested changes outside the scope of the simple hospital tool the client wanted, like connecting to an external SQL database or setting up a full GUI; instead, I decided to eventually implement a CSV creation function to save data safely without going outside the requested scope. I checked the AI's output by running the code in my IDLE and manually testing multiple scenarios from the lab handout, such as blank strings, double-booking time slots, and using None values. The engineering work I had to complete afterwards included fixing logic flaws like the input validation bug where a blank patient name did not trigger an error message because Python sees the empty string as false, so I added an explicit check (if not patient_name or not patient_name.strip():) to successfully catch the blank input and trigger an error.
